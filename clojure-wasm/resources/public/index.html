Clojure in the browser

server mode

A real JVM — OpenJDK compiled to WebAssembly via CheerpJ — running unmodified Clojure, entirely in this tab. No server round-trips.

user=>

First boot downloads the CheerpJ runtime + Clojure jars and compiles clojure.core inside your tab — expect ~30–120s, fast after caching. Reactivity by datastar; no React harmed. Append ?mode=server to eval on the dev server JVM instead, or ?java=17 to boot a Java 17 runtime.
