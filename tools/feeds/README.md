# Feed Preview

![Feed Preview](../../docs/screenshot-feeds.png)

Feed Preview displays Atom and RSS 2.0 feeds as readable entries in the browser.
Paste feed XML or enter a feed URL, then use **Preview feed** to render it.

The built-in Atom and RSS samples demonstrate both supported formats. Press
⌘/Ctrl + Enter to preview from the text area.

Part of the [`tools`](../../) monorepo. Deployed at
[`tools.kirahowe.com/feeds`](https://tools.kirahowe.com/feeds).
