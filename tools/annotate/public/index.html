Annotate a page for an LLM

Load a public web page (a book chapter, an article, a spec), highlight the exact passages you want to comment on, and export your notes in a format an assistant can act on — each note tied to the precise span of text it refers to.

  1. Paste a URL above and press Load — or use Paste to drop in text directly.
  2. Select any text and tap Add note.
  3. Press Export and paste the result into your LLM.

Your notes are saved on this device. Nothing is uploaded except the page URL, which is fetched through this site's own proxy so it loads despite cross-origin restrictions.
