# tools

Small tools, one directory each.

- [**clojure-wasm**](./clojure-wasm/) — a real JVM Clojure REPL running in
  the browser (OpenJDK on WebAssembly via CheerpJ), with a survey of the
  JVM-in-the-browser landscape. First step toward running
  [Clay](https://scicloj.github.io/clay/) notebooks on users' hardware.
