# tools

Small tools, one directory each.

- [**clojure-wasm**](./clojure-wasm/) — a real JVM Clojure REPL running in
  the browser (OpenJDK on WebAssembly via CheerpJ), plus a notebook
  prototype with pluggable kernels (browser JVM / server JVM / scittle)
  and a survey of the JVM-in-the-browser landscape. First steps toward
  running [Clay](https://scicloj.github.io/clay/) notebooks on users'
  hardware.
